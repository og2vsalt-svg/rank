# rankvault

Private file hosting and sharing.

- Local vault in the browser (IndexedDB).
- Upload local files straight to the database (Supabase storage + public_shares).
- Professional Discord embeds on every share link.
- Soft size warnings only — no hard file limits.
- Sleek Apple-style animations (Framer Motion springs, frosted glass, subtle lifts).
- Dozens of specialized desks (soft quiet prism, soft quiet lattice, soft quiet mosaic, soft quiet brook, soft quiet atrium, soft quiet vault, soft quiet echo, soft quiet harbor, atrium, constellation, meadow, veil, and many more) — all prior features preserved.
- **Quiet Lantern** — multi-file drop that hangs files as soft glowing lanterns with gentle floating/pulsing light and spring animations on frosted glass. Batch-publish to the database with polished Discord embeds. Soft size warnings only.
- **Lumen Archive** — calm visual archive of recent public shares with live multi-file drop publishing to the database, type filters, spring-animated cards, and polished Discord embeds. Soft warnings only.
- **Quiet Ribbon** — multi-file drop that settles into a flowing horizontal ribbon of spring-animated frosted glass cards. Batch-publish to the database with polished Discord embeds. Soft size warnings only.
- **Quiet Cascade** — multi-file drop that cascades into spring-animated glass cards, then batch-publishes each to the database with polished Discord embeds. Soft size warnings only.
- Direct share page for instant DB uploads.
- **Lumen Fold** — drop multiple local files, fold them into one quiet share package with a rich Discord embed that lists companions. Soft warnings only.
- **Quiet Atlas** — calm visual map of recent public shares in a spring-animated grid with type filters. Click to open. Professional Discord embeds on every link.
- **Lumen Collage** — drop multiple images into a quiet grid, compose them into one polished collage image, and publish to the database with a Discord embed. Soft warnings only.
- **Lumen Quill** — compose a quiet note with optional local file attachment, spring preview, and publish to the database with a polished Discord embed. Soft warnings only.
- **Lumen Drop** — multi-file drop zone with live previews, spring animations, and batch database shares that return polished Discord embeds.
- **Lumen Weave** — flowing multi-file weave into the database with animated spring cards, soft slow warnings, and professional Discord embeds.
- **Lumen Studio** — compose a single file with custom title and caption, live Discord-style card preview, then publish to the database. Soft warnings only.
- **Lumen Constellation** — multi-file drop that settles into a spring-animated grid of glass cards; share each or all to the database and receive Discord embed links. Soft warnings only.
- **Lumen Stream** — flowing feed of recent public shares with spring-entry cards and quick local file drops.
- **Quiet Harbor** — calm docking space with pulsing lights for notes and files.
- **Lumen Gallery** — visual masonry of shared images with spring-expanded lightbox.
- **Soft Echo** — public short notes stream, no account required, accent colors.
- **Lumen Orbit** — files settle into a quiet orbiting visualizer with multi-file drops and Discord embeds.
- **Canvas Note** — draw on dark glass and share the image straight to the database.
- **Quiet Timeline** — calm vertical stream of recent public shares with spring-entry cards.
- **Soft Quiet Chronicle** — dated notes and optional files that publish to the database with Discord embeds and spring cards.
- **Lumen Pinboard** — pin local files to a shared visual board with live public pins, spring cards, and Discord embeds.
- **Lumen Pulse** — interactive pulsing feed of recent public shares. Drop a local file or note and watch it join the living beat with spring animations and Discord embeds.
- Searchable desks directory.
- Quiet notes desk.

No traces of boosting. Human-crafted feel.

Deployed on Vercel. Source under `og2vsalt-svg/rank`.
