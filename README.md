# rankvault

Private file hosting and sharing.

Drop local files into specialized desks. They settle into the database with professional Discord embeds on every link. Soft size warnings only — no hard limits. Sleek Apple-style spring animations and frosted glass.

New features:
- **Quiet Lighthouse** — drop local files or watch recent public shares light up. Soft rotating lighthouse beam on frosted glass. Shared caption, accent color. Publishes to the database with polished Discord embeds on every link. Soft size warnings only. No hard limits. Apple-style springs. All prior desks remain fully intact.
- **Quiet Ember** — drop local files. They settle as glowing embers in a quiet hearth of frosted glass with soft pulsing heat, rising shimmer, and gentle sparks. Shared caption, warm accent color, and polished Discord embeds on every share link.
- **Quiet Constellation** — drop local files. They settle as stars in a quiet constellation of frosted glass with gentle connecting lines and spring motion. Shared caption, accent color, and polished Discord embeds on every share link.
- **Quiet Aurora** — drop local files. They drift under soft northern lights of frosted glass with gentle spring waves. Shared caption, accent color, and polished Discord embeds on every share link.
- **Quiet Pulse** — drop a local file. It joins a living pulse of recent public shares with gentle heartbeat motion. Shared caption, accent color, and polished Discord embeds on every share link.
- **Quiet Quartz** — drop local files that crystallize into a quiet quartz formation of frosted glass with pulsing spring facets. Shared caption, accent color, and polished Discord embeds on every share link.
- **Quiet Grove** — drop local files under quiet leaves of frosted glass. Shared caption, accent color, gentle spring leaf motions, and polished Discord embeds on every share link.
- **Gallery** — a living view of recent public shares across desks. Each link carries a polished Discord embed.

All prior desks remain fully intact (Quiet Inlet, Quiet Tide, Quiet Orbit, Quiet Nebula, Keepsake, Spectrum, Ripple, Frame, Echo, Canvas, Notes, Orchard, Horizon, Harmony, Lumen, Prism, Harbor, Cove, Lantern, Cascade, and dozens more). No traces of boosting.

- Local vault in the browser (IndexedDB).
- Upload local files straight to the database (Supabase + optional Vercel Blob).
- Professional Discord embeds on every share link.
- Soft size warnings only. No hard file limits.
