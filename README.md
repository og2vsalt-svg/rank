# rankvault

Private file hosting and sharing.

- Local vault in the browser
- Upload to Supabase storage + public_shares table
- Professional Discord / social embeds on every share link via bot rewrites
- No hard file size limits — only soft warnings for large uploads
- Apple-style glass, spring animations, human-crafted feel
- Many specialized desks and pages

Live: https://rank-six-iota.vercel.app/
