# rankvault

Private file hosting and sharing.

Drop local files into specialized desks. They settle into the database with professional Discord embeds on every link. Soft size warnings only — no hard limits. Sleek Apple-style spring animations and frosted glass.

Central surfaces:
- **Core** — the quiet center. Drag local files or choose them. They settle into the database with a polished Discord embed on every link. Soft size warnings only — never hard limits. Apple-style spring motion on frosted glass.
- **Studio** — multi-file crafting. Drop several files, give each its own caption and accent color. Publishes to the database with professional Discord embeds on every link. Soft size warnings only. No hard limits.
- **Nexus** — centered file hosting. Drop files, publish to the database, copy a Discord-ready link. Recent public shares live here.
- **Quiet Solace** — calm drop with optional soft expiration. Frosted glass, gentle springs.
- **Quiet Horizon** — the far edge of recent public shares, plus new drops.
- **Canvas Forge** — freehand sketching canvas. Draw, export as PNG, share with Discord embed.
- **Weave** — multi-file drop where each file gets its own caption and accent before independent publish.
- **Audio Desk** — record a voice memo in the browser and publish it as a file with a polished Discord embed.
- **QR Desk** — stamp text or a link into a visual image and publish it with a Discord embed.

Specialized desks (all prior remain fully intact):
- **Quiet Harbor**, **Quiet Lighthouse**, **Quiet Ember**, **Quiet Constellation**, **Quiet Aurora**, **Quiet Pulse**, **Quiet Quartz**, **Quiet Grove**, **Gallery**, Quiet Inlet, Quiet Tide, Quiet Orbit, Quiet Nebula, Keepsake, Spectrum, Ripple, Frame, Echo, Canvas, Notes, Orchard, Horizon, Harmony, Lumen, Prism, Harbor, Cove, Lantern, Cascade, and dozens more.

No traces of boosting.

- Local vault in the browser (IndexedDB).
- Upload local files straight to the database (Supabase + optional Vercel Blob).
- Professional Discord embeds on every share link.
- Soft size warnings only. No hard file limits.

Deployed on Vercel. Source under `og2vsalt-svg/rank`.
