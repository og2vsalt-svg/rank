# rankvault

Private file hosting and sharing.

- Local vault in the browser (IndexedDB).
- Upload local files straight to the database (Supabase storage + public_shares).
- Professional Discord embeds on every share link.
- Soft size warnings only — no hard file limits.
- Sleek Apple-style animations (Framer Motion springs, frosted glass, subtle lifts).
- Dozens of specialized desks (soft quiet prism, soft quiet lattice, soft quiet mosaic, soft quiet brook, soft quiet atrium, soft quiet vault, soft quiet echo, soft quiet harbor, atrium, constellation, meadow, veil, and many more) — all prior features preserved.
- Direct share page for instant DB uploads.
- **New: Lumen Drop** — multi-file drop zone with live previews, spring animations, and batch database shares that return polished Discord embeds.
- **New: Lumen Stream** — flowing feed of recent public shares with spring-entry cards and quick local file drops.
- **New: Quiet Harbor** — calm docking space with pulsing lights for notes and files.
- **New: Lumen Gallery** — visual masonry of shared images with spring-expanded lightbox.
- **New: Soft Echo** — public short notes stream, no account required, accent colors.
- **New: Lumen Orbit** — files settle into a quiet orbiting visualizer with multi-file drops and Discord embeds.
- **New: Canvas Note** — draw on dark glass and share the image straight to the database.
- **New: Quiet Timeline** — calm vertical stream of recent public shares with spring-entry cards.
- Searchable desks directory.
- Quiet notes desk.

No traces of boosting. Human-crafted feel.

Deployed on Vercel. Source under `og2vsalt-svg/rank`.
