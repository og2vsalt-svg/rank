# rankvault

Private file hosting with dozens of specialized desks.

Drop local files. They upload to Supabase storage and public_shares. Optional notes land in whispers. Every share link (`/s/:id`) carries a polished Discord embed via middleware and `/api/card`.

Soft size warnings only — never hard limits. Apple-style spring animations on frosted glass. Human-crafted UI.

Desks include Core, Gallery, Timeline, Quiet Harbor, Quiet Signal, Quiet Inspector, Lens, Diary and many more. All prior desks remain fully intact.

## Stack

- Vite + React + Tailwind + Framer Motion
- Supabase (public_shares, whispers, storage)
- Vercel (serverless APIs, Blob optional)
- Discord / social embeds on all share links

No boosting. Just quiet, reliable file sharing.
