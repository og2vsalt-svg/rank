# rankvault

Private file hosting and sharing.

- Local vault in the browser (IndexedDB).
- Upload local files straight to the database (Supabase storage + public_shares).
- Professional Discord embeds on every share link.
- Soft size warnings only — no hard file limits.
- Sleek Apple-style animations (Framer Motion springs, frosted glass).
- Dozens of specialized desks (soft quiet lumen, soft quiet harbor, atrium, constellation, meadow, veil, and many more) — all prior features preserved.
- New direct share page for instant DB uploads.
- Quiet notes desk for short text notes that land in the database with Discord embeds.

No traces of boosting. Human-crafted feel.

Deployed on Vercel. Source under `og2vsalt-svg/rank`.
